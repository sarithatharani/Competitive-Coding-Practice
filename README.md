# Competitive Coding Practice

Daily practice log of problems solved on **LeetCode** and **Codeforces** —
solutions, along with notes on the approach/logic used for each.

## Structure

```
competitive-coding-practice/
├── leetcode/
│   └── <problem-name>/
│       ├── Solution.<ext>
│       └── README.md
├── codeforces/
│   └── <contest><problem>-<problem-name>/
│       ├── <ContestProblem>_<ProblemName>.<ext>
│       └── README.md
└── gfg/
    └── <problem-name>/
        ├── Solution.<ext>
        └── README.md
```

Each problem gets its own folder with the code and a short README
explaining the approach/logic.
